# Failure-Critical Final Audit Contract Repair V1

The first independent final audit correctly recomputed the frozen statistics
but failed one otherwise complete branch because its implementation required
an extra direct-render hash to equal the bank-time direct-render hash. The
prospective protocol requires exact archived prefix state, proprioception and
the policy-returned dual-camera input. It does not make an additional direct
renderer call part of the scientific equality gate. Prior Raster Contract V2
also explicitly retained direct rendering as audit metadata.

This zero-GPU repair changes only the independent audit predicate: both direct
renderer SHA-256 values must remain present and well formed, while equality is
required for the policy observation hashes. It does not change any trajectory,
candidate, label, complete-group decision, bootstrap seed, threshold, or final
scientific status. The failed original audit and source remain preserved. The
repaired source is written under a new filename and output directory and may
run exactly once against the already frozen final report.
